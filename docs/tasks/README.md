# Implementation Task Specifications

This directory contains implementable work packets linked to GitHub issues.

A task should normally change one coherent capability and be reviewable as one focused diff. Broad epics must be decomposed before implementation.

## Template

```markdown
# Task: Title

## Context and user value

## Current behavior

## Desired behavior

## In scope

## Out of scope

## Architecture constraints

## Security and privacy constraints

## Acceptance criteria

- [ ] AC-1
- [ ] AC-2

## Required tests

## Validation commands

## Documentation and ADR updates

## Known dependencies
```

Every completed task must include the evidence report required by the root `AGENTS.md`.
